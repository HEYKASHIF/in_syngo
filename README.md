# IN_SYNGO 📢❤️

_A Flutter-based Donation App That Connects People, NGOs & Social Impact_

**IN_SYNGO** is a modern and minimal mobile application designed to reduce waste and support the underprivileged by connecting **donors with NGOs**. This app helps users donate unused resources like clothes, medicines, stationery, toys, food, and electronics to those in need.

> "On one side, people throw away useful items. On the other hand, many are struggling without basic necessities. IN_SYNGO bridges this gap."

---

## 🌟 Features

- 💊 **Donate Medicines** – Contribute unused but safe medical items  
- 🧢 **Donate Clothes** – Share warmth through jackets, shirts, or blankets  
- ✉️ **Donate Stationery** – Help kids study with notebooks, pens, and school gear  
- 🎮 **Donate Toys** – Bring smiles to children through your old toys  
- 🥽 **Donate Food** – Share meals that matter (non-perishable)  
- 📱 **Donate Electronics** – Give your unused gadgets a second life  
- 🏛 **NGO Integration** – Connects directly with trusted NGOs near you  
- ⏳ **Easy & Quick Donation Flow** – Pick item > Add details > NGO picks it up  

---

## 🎓 Who Can Use This App?

- Individuals and families who want to **donate** unused items  
- NGOs and welfare organizations collecting donations  
- Volunteers working with the needy  

Whether you're a student, professional, homemaker, or businessperson, you can **give back with ease**.

---

## 📅 How It Works

1. Select a donation category (e.g., food, clothes, toys)  
2. Add details and your location  
3. Choose an NGO (or auto-assign)  
4. The NGO arranges pickup or guides you for drop-off  
5. Receive confirmation and earn **Respect Points**

> A simple way to create impact – one item at a time.

## 🚀 Getting Started

### Clone the repo
```bash
git clone https://github.com/HEYKASHIF/in_syngo.git
cd in_syngo
```

### Install dependencies
```bash
flutter pub get
```

### Run the app
```bash
flutter run
```

> Make sure you have Flutter set up with an emulator or device connected.
